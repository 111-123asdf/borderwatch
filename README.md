# 边境守望 v0.23

五名英雄、七类三级塔、四张固定塔位地图。边境林地、紫雾遗迹及白帆盐港各八波，溪谷驿站十波。永久等级 2、4 分别解锁小技能和大招。

## 运行与操作

Windows 试玩包解压后双击 Play.bat。Play-HeroLab.bat 进入五英雄的 5 级试招场。源码使用 Godot 4.7.2 Standard 打开，兼容模式，入口 scenes/arena.tscn。

WASD 或方向键移动，右键点地，左键可按住普攻，Q 小技能，E 大招。点塔位建造，点塔升阶、出售或换旗，震地炮可指定落点，绊索工坊可换设索路口。Esc 暂停或取消选点，H 打开手册。选好开局或波间的祝福和代价后，按 B 打开战场指令。工坊可从七种塔中装备一至四种，部署时锁定。

遗迹用中键或边缘移镜头，M 全图、C 英雄、G 吊桥、R 共鸣。第四波破障和时停祭坛继续生效。盐港保留双路、十二塔位及海港敌军。溪谷要布置防空，并处理第六波的暗钢犀牛和第十波的双头巨魔。

## 开发与验证

正常档使用 campaign_v3.cfg，试玩使用 playtest_v013.cfg。条件被动、四塔实验用 tools/run.ps1 的 -ConditionLab、-TowerLab 选项进入。

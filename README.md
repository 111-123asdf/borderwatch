# 边境守望 · v0.6
操作英雄拦怪、躲弹和救场，在固定塔位建设防线，趁空隙清理营地获得成长。两张全图可见的森林战场，各八波。

## 运行
Windows试玩包解压后双击Borderwatch.exe，无需安装引擎。源码用Godot4.7.2 Standard / Compatibility导入本目录project.godot；Windows也可双击开发编辑器.bat或试玩.bat。主菜单选英雄，再选边境林地或溪谷驿站。

## 操作
- WASD／方向键移动；右键点地前往，键盘立即覆盖路径。英雄不自动远距离追敌。
- 按住左键普攻并自动锁定范围内目标。Q小技能，Space大招；技能图标也可点击，指向技能再点落点，右键／Esc取消。
- 点击路旁空塔位建造，点已有建筑升级、出售或切换优先目标；兵营可调整到附近道路集结。塔无血量。
- 休息期点怪物图案预览，再点提前开波，按剩余时间奖励至多12金币；到时自动开波。
- 升级三选一可用鼠标或1／2／3。Esc暂停，H查看手册。

骑士擅长拦截与近战，游侠点杀与翻滚，法师范围法术与控制。连续5秒脱战后回血；英雄倒下15秒在基地复活，技能冷却继续计时，基地失守才失败。

弓箭塔、火炮、骑士、游侠及士兵造成物理伤害；法师与法师塔造成法术伤害。重甲抗物理、幽光抗魔法，鼠标停留怪物可查看抗性。第一关先开放弓箭塔与兵营，第3波法师塔、第5波火炮塔；第二关四塔均可用。

本版本没有武器掉落、换装、背包、能量、护盾或跨局英雄训练。英雄攻击与双技能由职业固定；击杀金币与经验自动到账，每关重置局内状态。历史版本生成的训练存档保持原样，但当前版本不再读取或改写。

## 开发与验证
唯一入口scenes/arena.tscn，两关通过ArenaLevelCatalog配置，共用战斗代码。PowerShell执行tools/verify.ps1、tools/export.ps1、tools/verify_export.ps1。测试边界见docs/TESTING.md，实际结果见docs/RELEASE_NOTES.md。素材来源见docs/ASSET_SOURCES.md。仓库不带引擎、缓存或发行二进制，GitHub操作由负责人手动完成。

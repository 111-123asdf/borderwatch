# 边境守望 v0.13 · 局外界面重构

标题、世界地图、关卡预览、英雄大厅、防御塔工坊与40卡成长图鉴统一为干净卡通界面。半身像放入卡牌框，属性使用图标/进度条；技能和改造说明可直接点选，同页切换不重建背景。三英雄与局内战斗保持。

外层“试玩.bat”或成品包“Play.bat”进入自由试玩：初始英雄LV.1、9999局外钻石，可自己点升级。试玩档playtest_v013.cfg独立保存，重进补足钻石，正常campaign_v3.cfg保留。直接运行EXE或F5为正常进度入口。Q小技能、E大招。

“英雄手感实验.bat”仍可切三英雄、新旧表现、尺寸与减少动态，使用不持久化5级夹具。界面与试玩边界见docs/UI_OVERHAUL_V013.md，英雄表现见docs/HERO_FEEL_V012.md。

操作英雄拦怪、躲弹和救场，在固定塔位建设防线，趁空隙清理营地获得成长。两张全图可见的森林战场，各八波。

## 运行
Windows试玩包解压后双击Borderwatch.exe，无需安装引擎。源码用Godot4.7.2 Standard / Compatibility导入本目录project.godot；Windows也可双击开发编辑器.bat或试玩.bat。「开始」进入世界地图，点击1或2号关卡，再点「出战」。地图底部进入英雄、防御塔、成长页面，角落调整设置。

英雄页先浏览，再点击「出战」设置唯一出战英雄；选关直接带已配置英雄进入，不再重复选择。塔页管理四个槽，默认四类全装，可卸下/装回，至少保留一类。没有首波可建塔时，关卡面板提供配置入口。局内只能建已装备且达到本关开放波次的塔。配置会保存，升级与三级改造仍在关卡内完成。

世界包含森林、雪山、荒地、遗迹等不同地貌，当前可玩的两关都在森林区域，其他地貌暂为远景。管理页采用中性石木庭院、皮革和羊皮纸；地图节点、关卡故事与场景图片由关卡配置提供。界面说明见docs/UI_WORLD_LOADOUTS.md。

## 操作
- WASD／方向键移动；右键点地前往，键盘立即覆盖路径。英雄不自动远距离追敌。
- 按住左键普攻并自动锁定范围内目标。Q小技能，E大招；技能图标也可点击，指向技能再点落点，右键／Esc取消。
- 点击路旁空塔位建造，点已有建筑升级、出售或切换优先目标；兵营可调整到附近道路集结。塔无血量。
- 休息期点怪物图案预览，再点提前开波，按剩余时间奖励至多12金币；到时自动开波。
- 升级三选一可用鼠标或1／2／3。Esc暂停，H查看手册。

骑士擅长拦截与近战，游侠点杀与翻滚，法师范围法术与控制。新档英雄1级，永久2级解锁Q、4级解锁大招。连续5秒脱战后回血；兵营士兵同样脱战5秒后每秒恢复最大生命的10%。英雄倒下15秒在基地复活，技能冷却继续计时，基地失守才失败。

弓箭塔、火炮、骑士、游侠及士兵造成物理伤害；法师与法师塔造成法术伤害。重甲抗物理、幽光抗魔法，鼠标停留怪物可查看抗性。第一关先开放弓箭塔与兵营，第3波法师塔、第5波火炮塔；第二关四塔均可用。

本版本没有武器掉落、换装、背包或能量。英雄攻击与双技能由职业固定；击杀金币与经验自动到账，每关重置局内状态。卡牌可以提供过量治疗转临时吸收，不恢复旧护盾训练。

## 英雄养成
三英雄各自1—5级，共用钻石。升级依次花费2／3／5／8钻石，单英雄总计18。满级累计生命+8%、普攻+6%，职业被动在3、5级强化，局内成长仍是主要力量。结算获胜6钻，每关首次胜利额外2；失败时完成4—5波获2钻，6—7波获3钻，提前退出无奖励。每局只入账一次，写盘失败可在结算重试，升级保存失败不扣费。

养成、设置与出战配置保存在user://campaign_v3.cfg（Windows通常为%APPDATA%/Borderwatch）。旧v3档缺少配置字段时只在内存补骑士/四塔默认值，保留钻石与等级，确认配置时才保存。历史v1/v2训练存档不读取、不迁移、不改写。异常存档仍保留原件。

整合内容包括新菜单与引导、40张成长卡及联动、主菜单和暂停手册中的被动图鉴。塔升级到三级后选择一项改造。营地第2波激活，第4波未清则光环扩散，第5波派出突袭队；清理后选择英雄成长、免费三级改造券或100金币。改造券仅本局保留。每图有一个200金币解锁的额外塔位。

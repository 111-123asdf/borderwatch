# 边境守望

三英雄、七类三级塔、三关八波。每局最多携带四种塔。玩家在固定塔位组织防线，亲自控制英雄拦怪、躲弹和救场。

## 出战与守线

在世界地图的「防御塔」工坊选择出战塔。勾选标记表示已装备，四格已满时点「替换出战塔」并选要换下的一种。本局阵容在出战时锁定，同种塔可以重复建造。穿云弓贯穿敌列并给英雄制造破绽，霜环塔在内圈更快冻结，震地炮可预设落点，哨卫营可换旗守路。跃电塔适合接连清理分散小队，聚光塔持续照射重甲，绊索工坊可在敌人经过前移索封路。

正式流程会在开局和每个非末波结束时给出最多三张打法牌。12 种祝福共有 17 种配对，每局保留选中的祝福和代价。按 1／2／3 或点击选牌。选「常规守线」可完整走一局基础对照。[关卡与战斗设计](docs/BATTLE_RULES.md)

获得主动打法后，点屏幕左下「战场指令」或按 B。整备时可以插接应旗、安排诱敌和签悬赏，交战时可以换防、推敌或调用城防。需选目标的指令再点地面、塔或被拦住的敌人，右键或 Esc 取消。钱箱可直接在金币栏下方领取。手册列出本局各张牌的完整代价。

## 运行与操作

在工程目录运行 `./tools/run.ps1 -Playtest` 体验当前版本。也可用 Godot 4.7.2 Standard 导入 `project.godot` 后按 F5，入口为 `scenes/arena.tscn`。追加 `-Stage ruins` 可直达遗迹。

WASD/方向键移动，右键点地移动，键盘立即覆盖。按住左键普攻并自动锁敌；Q小技能、E大招（永久2/4级解锁）。点塔位建造，点塔升级、出售、选目标、设旗位或指定炮击落点。英雄倒下15秒复活，基地归零即失败。核心存活并清完波次、有首领的关卡同时击败首领才胜利。Esc暂停/取消选点，H手册。怪物按钮点击预览、再次点击提前开波，最多奖励12金。

前两关森林/溪谷全图。第三关遗迹2000×1125、18塔位，第四波破障新增支路；中键/边缘移镜头，M全图、C英雄、G桥、R共鸣。桥等待既有单位通过，分岔后不切换敌人曲线。

--playtest独立playtest_v013.cfg，初始LV.1、9999钻石，重进补足；局内资源正常。正常档campaign_v3.cfg与旧训练档不受影响。--feel-lab是不持久化5级夹具。

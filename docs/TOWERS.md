# 出战阵容与防御塔

世界地图的工坊提供七种塔。每局最多携带四种，出战时锁定。每种可以占多个塔位。默认沿用原四塔，已有阵容按存档顺序保留。四格已满时，玩家点选一种新塔，再点要换下的旧塔。正式森林关首波就可用全套出战阵容。

| 塔 | 造价 | 建在哪、怎样操作 |
|---|---:|---|
| 穿云弓 | 70 | 放直路旁。自动寻找可贯穿的敌列，一、二阶最多穿四敌，三阶五敌。英雄在三秒内命中可兑现一次 30% 加伤。 |
| 霜环塔 | 100 | 放弯道内侧。内圈全伤、叠两层霜，外圈半伤、叠一层，基础三层冻结。奥火改造转清群，破法改造转单体。 |
| 震地炮 | 120 | 自动选敌群，或指定要守的路口。冲击内圈占爆炸半径 55%，造成震退和短晕。精英和首领的控制效果会减弱。 |
| 哨卫营 | 80 | 三人分担轻敌，可拦轻型精英。换旗时先放手、再走到新岗。三级兵员生命为 160／220／280，补员间隔为 8／7／6 秒。 |
| 跃电塔 | 105 | 放在两股敌人相距不远的路段。首击 28 法伤，随后每跳在 105 距离内找一个未命中的目标，每跳保留 70% 伤害，基础最多击中三敌。可改造以增加跳数、跳距或首击威力。 |
| 聚光塔 | 125 | 放在能长时间照到同一重甲或首领的路段。首击 17 法伤，连续追加每击增加基础伤害的 35%，至多四层。换敌、目标死亡或出射程清零。可改造以强化聚焦、首击或射程。 |
| 绊索工坊 | 85 | 初始在近路设索，可点塔选「设绊索」移到另一路口。一级收网半径 56，敌人进入内侧六成时触发。普通敌减速 45% 持续 1.8 秒，精英减速 25%，首领受短暂控制。移索至少等待 1.2 秒，移动也要等剩余装填完成。可改造以扩大收网、穿甲或缩短装填。 |

正式战局保留塔位加成、三级改造和双分支。基础弓、霜、炮的一级攻击间隔分别为 1.35、1.85、2.35 秒。弓塔和法师塔继续支持借台射击，聚光和跃电可参与点名集火。固定炮击点和绊索由玩家选位。

## 施工与联动

建造和升阶需要 1 秒。施工前扣金币，取消返还该次实付。新塔完工才出手，升阶中的塔继续按旧等级工作。出售按已完工的实际投入计价；整备换阵可在整备时返还 100%，波中锁住建造、升级、开新塔位和出售。炮击落点与兵营旗位仍可调整。

弓在蓄力起点锁定贯穿方向；英雄的一次有效命中消耗破绽。霜环内圈半径是外圈的 62%。定点炮预判敌人会进入内圈才装填。哨卫撤离旧岗后沿地面步行，抵达新岗才拦人。精英与首领的连续控制有衰减和保护窗口。

四塔实验入口保留早期参数作对照，例如一级穿云弓的攻击间隔为 2.2 秒，正式版为 1.35 秒。射线、寒霜叠层、炮击预判与换旗使用同一套机制。[实验与正式参数](../scripts/arena/arena_tower_trial.gd) · [三级改造及分支](../scripts/arena/arena_doctrines.gd) · [阵容回归](../tests/v021_tower_roster.gd)

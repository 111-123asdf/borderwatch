# 手感回归与录屏验收

每次修改动作、镜头、特效、声音、HUD或重构战斗后执行。记录版本/工作区、英雄与永久等级、关卡、窗口尺寸、是否使用夹具、正常/减少动态设置及录屏路径。结果分“技术通过”“负责人体验认可”“未测”，不要互相替代。

## 必查行为

- 按住左键才普攻，点界面不攻击；每次接触只结算一次。主动技能出手与伤害同步，取消选点不扣冷却，移动取消后摇不加快攻击。
- 局部停顿结束能恢复，连续命中不会延长成卡死；全局停顿限流。暂停、重开、胜负结算不遗留慢速、推近或相机偏移。
- 英雄和敌人的视觉缩放、挤压、推移不修改碰撞、伤害类型、拦截容量或射程；击退仍沿道路进度，首领免拦截保持。
- 塔的根部、地基和碰撞稳定，升级实际数值与图形一致；后坐不摆动建筑本体。
- 敌人死亡立即释放目标和拦截关系，击杀收益只记一次；金币飞行和碎屑丢帧不影响资源到账。
- 英雄伤害数字不夹带塔伤；按目标合并，未定义的暴击事件不凭数值猜测。
- 普攻、技能、命中、击杀可听辨，变体不爆音、不反复切断重要声音；Music/SFX/UI分别受音量控制，退出无音频对象泄漏。
- 1024×576仍看得清出手、敌弹、道路和基地；大量命中不遮住战局。减少动态模式可完整游玩。
- 新旧存档、英雄解锁、出战配置、正常资源与两关胜负流程不因表现改动变化。

## 负责人看什么

每项先给约15秒原版/改版对照，标明参数和相同触发条件。骑士黄金样板给约30秒：走动、一次普攻、技能救场、击杀和一次建塔。主动技能使用符合解锁条件的档位；夹具明确标记。

静音观察接触、敌人反应和动作恢复；只听音频分辨动作类别；正常观看判断是否有力、清楚且不累眼。负责人反馈一句最明显的问题即可。未认可时保留小样，不把局部方案批量推广。

自动规则测试与成品检查继续保留。通过数量只作为回归证据，不作为爽感、美术或真人试玩通过的依据。

# 被动深度重构

## 目标

把 89 张卡从“线性数值池”改造成“核心 → 分支 → 终式”的构筑体系，并保证没有一张卡在正常局内完全无用。

## 当前架构

### 流派标签

| 流派 | 核心 | 二选一分支 | 终式 |
| --- | --- | --- | --- |
| 火焰 | 燃烧 | 野火 / 热震 | 焚城 |
| 冰霜 | 霜附 / 霜环 | 永冻 / 深寒 | 绝对零度 |
| 雷电 | 连锁 | 雷暴 / 导电 | 雷神 |
| 弹道 | 多重/穿透/暴击 | 弹幕 / 处决 | 待做 |
| 塔防 | 塔链/塔网 | 堡垒/超载 | 塔防协议 |
| 生存/职业 | 护盾/体魄/职业 | 职业分支 | 待做 |

### 层级

- 0 层：核心卡，拿到就有基础收益
- 1 层：同流派累计 2 层，保证出现一张分支
- 2 层：累计 3 层，出现终式前置条件
- 3 层：累计 5 层，终式

### 发牌保证

- 同流派达到 2 层且没有分支：
  - 三选一里至少出现一张该流派分支
- 达到终式前置：
  - 终式进入卡池并提高权重
- 没建塔：
  - 所有纯塔防卡不再出现在池子里
  - 避免“没塔时塔卡=0”

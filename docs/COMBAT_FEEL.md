# 打击感专项

## 目标

不是再加数值，而是让每次命中都有**可感知的反馈层**。

当前实现：

- hitstop
- 命中火花
- 伤害数字（暴击更大）
- 击退
- 敌人白闪
- 击杀爆裂
- 枪口火光/后坐
- 塔炮口火光
- 方向性镜头震动
- 程序化音效

## 1. Hitstop

- 普通命中：18ms
- 暴击：38ms
- 击杀：40～60ms
- 同一时间有 70ms 冷却，避免高射速武器把游戏冻住
- 使用独立 `game.hitstop`，不直接改 `Engine.time_scale`，不会破坏建造模式 0.45 慢速

敌人、英雄、塔、弹道在 hitstop 期间停止更新，相机和特效继续。

## 2. 命中反馈

每次命中：

- 敌人白闪（ActorVisual）
- 金色冲击环
- 4～7 个火花粒子
- 伤害数字
- 暴击数字带 `✦`、字号更大、颜色更亮
- 击中方向上的镜头震动

## 3. 击退

- 普通怪：28px 击退
- 暴击：46px 击退
- 精英：×0.55
- Boss/冻结目标：不击退
- 击退会快速衰减，不会把怪推出地图

## 4. 死亡反馈

- 死亡冲击环
- 火花爆发
- 精英更多火花
- 击杀 hitstop
- 程序化击杀音
- 原有金币掉落保留

塔被摧毁也有爆炸环、火花、震动和音效。

## 5. 武器反馈

手枪/弓/法杖共用：

- 枪口火光锥
- 枪口亮点
- 枪身后坐
- 弹道拖尾
- 开火音效

暴击有独立音高和数字样式。

## 6. 镜头

- `shake(amount, direction)` 支持方向性震动
- 命中沿攻击方向抖
- 击杀/爆炸才明显抖
- 原有随机震动保留给无方向事件

## 7. 音效

没有使用外部商业音频；运行时生成 PCM 波形：

- 开火
- 命中
- 暴击
- 击杀
- 受伤
- 塔开火
- 爆炸
- Boss 阶段

8 个 AudioStreamPlayer 轮转，带 45ms 节流和随机音高。

## 8. 验证

- `tools/verify_arena.ps1`：94 项
- 新增：
  - 暴击 hitstop/火花
  - 程序化音频流存在
  - 敌人击退
  - 点击塔外关闭面板
- 打磨重点仍是真人试玩：数值正确不等于手感好。

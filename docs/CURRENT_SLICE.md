# 当前核心切片

> 2026-10-24：主场景已切到竞技场迁移版 `scenes/arena.tscn`。本文描述旧 core-slice（`scenes/main.tscn`），保留为回归基线和旧模式参考；当前玩法见[竞技场迁移记录](ARENA_MIGRATION.md)。

基线是2026-10-21队友源码包，负责人明确以此为主线。内部版本0.3.0，内容标识core-slice-preview。旧完整0.3不是当前验收标准。

## 核心循环

选英雄→建起步防线→准备期/波间探索→清营地、开宝匣、选路线→回防→升级塔→六波与Boss。近英雄340范围有指挥光环；英雄离开塔会变弱。核心不自动修复，漏怪和回防错误会留下损失。

## 开放内容和保留定义要分开

- 开局180金，弩塔100。先放一座剩80，不能直接付两座；首营地奖励120金，可先探索再补塔。
- 普通起手按职业是手枪/弓/法杖；三个宝匣依次直接换法杖、狙击、月轮，等级随宝匣顺序。没有自由装备菜单、仓库或工匠强化店。
- Rules保留11武器定义，ACTIVE_WEAPONS列四项，但该表不是实际武器选择菜单；不要把保留代码的全部武器宣传为当前可获得。
- 三英雄各一个主动；只有游侠翻滚，骑士是限时双持复制，秘术师结界清弹。
- 三营地各一节点，按完成0/1/3波解锁；伙伴保留但不再是旧强化商店。每清营地全塔增加12%伤害。
- 当前开放弩塔和首营地解锁的重炮。寒霜定义保留但不在建设列表。塔位随营地和路线变化，最高4级。
- 三组成长各二选一且互斥：孤塔/群塔、亲征/指挥、急袭/深耕。击杀经验只加生命上限，路线来自营地。
- 首波90秒自动开，波间基础55秒，节奏路线改变准备时间；提前开波不额外发钱。
- Threat统一血量压力：每波0.15、每清营地0.05；不要引用旧分析稿的0.2/0.6。

## 已知不足

部分教程/按钮仍写仓库、无限准备等旧词，部分旧被动分支恒为0。双持机枪等保留代码可供夹具摆位，但不是普通装备流程。已有完整机器人证据集中在群塔/指挥/深耕；另外三条路线有局部断言，不能宣称8种组合都已通关和平衡。

四个受限机器人失败只支持当前策略下互相依赖的设计假设，不证明所有真人策略都绕不过探索。本次整理不擅自调数值或加功能，下一步优先真人首玩与文字可读性。

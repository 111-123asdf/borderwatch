# v0.13 · 局外界面与交互

本轮围绕负责人提供的Jamma方案和英雄大厅概念图实施，保留骑士v011、游侠/法师v012角色身份与战斗表现。标题、世界地图、关卡预览、英雄大厅、防御塔工坊和成长图鉴采用同一套深色描边、干净色块、冷调石板与金色强调。不同地区仍有自己的森林、雪山、荒原和遗迹配色，没有把世界统一染绿。

## 当前页面

- 标题使用当前三英雄同框的原创主视觉，程序渲染真实中文标题；仅保留开始、设置和退出三个操作。
- 世界撤下通栏木梁。左下为当前英雄及四塔的紧凑配置托盘，右下为三个悬浮徽章。只有两个真实可玩节点，远景地区以雾和弱化锁标记；只显示既有通关标记，没有虚构三星评分。
- 关卡预览使用地形横幅、真实敌人头像、两行简报、波数与现有钻石奖励，突出战斗按钮。首波塔池不满足时仍提供配置入口；Esc、关闭和点击外部取消。
- 英雄半身像放入带实际裁切区的竖版卡框，脚部截断收在框内。生命、普攻与每秒攻击次数来自实际基础配置和永久加成。三个技能按钮都能切换常驻说明；未解锁仍可预览效果。等级为非按钮星槽，升级时只更新属性、星槽和卡牌反馈。
- 工坊沿用卡框与属性条，四塔、三级外观和三条实际改造路线都能局部预览。塔属性为该阶基础值，路线效果说明来自ArenaDoctrines，局外预览不消费金币、不预设关内改造。
- 图鉴保留原40卡、全部级别效果、联动条件和套装。新增40个原创图标，按现有锋刃/星火/壁垒/号令及职业/进化筛选，颜色区分构筑轴与稀有度，右侧固定详情可滚动。

## 交互实现

ArenaFrontEnd只在跨页面时重建菜单。英雄、塔、阶级、技能和改造预览更新已有节点，背景、顶部栏与卡框保持同一实例；没有整屏透明淡入。所有可点击元素都有真实动作，等级星槽等纯展示使用TextureRect。按钮悬停1.04、按压0.96、80ms缓动；减少动态时取消缩放。升级属性条与数值滚动，卡牌短暂金色反馈。室内没有漂浮尘点，标题/世界仅有少量柔和光点。UI点击使用已许可CC0采样，走Interface声部。

ArenaMenuArt集中图集区域、按部件归一化的底板/按钮、小尺寸圆角样式与按钮反馈。大面板、小按钮、主操作和卡牌框分别处理，不再把40px大切角框套到所有控件。生成原件、提示与SHA256在ART_GENERATION_V013.json；tools/prepare_ui_art.py按负责人明确要求做透明边缘清理、裁切及控件归一化，原始输出保持。运行只需PNG/JSON，不依赖Python图像库。

方案中的角色、技能和路线示例按现有游戏校准：游侠仍为栗发青年男性，法师露面；骑士Q为震地斩、游侠Q为翻滚。保留每塔三条真实路线，不减少为两条。物理/法术仍是两种伤害，火炮爆炸属于范围物理伤害。

## 新按键与自由试玩

按最新反馈，大招改为E，小技能仍Q；战斗HUD、手册、英雄页、实验场和窗口测试一致。Space不再释放大招。

外层试玩入口及成品包Play.bat以`--playtest`启动独立`user://playtest_v013.cfg`。首次英雄为原始LV.1（即尚未升级），给9999局外钻石，可直接点完三个英雄的升级和技能解锁。重进试玩时钻石至少补至9999，已点等级与配置保留。正常`campaign_v3.cfg`不读取、不迁移、不覆盖；直接启动EXE或F5仍是正常进度入口。局内开局金币、生命、伤害和奖励规则保持。`--feel-lab`优先使用原有不持久化5级夹具。

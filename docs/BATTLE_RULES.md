# 守线、波次与战场指令

| 项目 | 已确认的规则 |
|---|---|
| 失败 | 敌军摧毁己方核心，立即判负。 |
| 胜利 | 己方核心仍存活，完成本关所有波次并击杀编入波次的 Boss。Boss 单独被击杀时，尚未完成的波次仍须处理；最后一波尚有待出敌军或 Boss 存活时，继续战斗。 |
| 建造 | 沿用各关固定塔位及既有开启规则。争地和修塔暂搁置。 |
| 关卡 | 森林单路、溪谷双路、遗迹多路。战斗使用三关各自的固定道路、塔位和机关。 |
| 自选打法 | 移除局内英雄经验、经验升级及被动卡。开局和每个非末波结束时，加选一种可以主动追求的打法。每张候选由一条祝福和一条同类代价组成，选过的都保留到局末。 |

## 抽牌与下令

开局和前七波结束时，从当前可用的祝福中最多抽三种。先选类别，再选该类祝福及其兼容代价。一轮内祝福不重复，优先展示尚未见过的祝福。选定后两面保留到局末。零张可用时直接整备。「常规守线」保留基础玩法。主动打法通过 B 或「战场指令」操作，手册显示本局完整配对。[抽取与卡池](../scripts/arena/arena_rule_deck.gd)

| 类别 | 完整牌面 | 值得拿它的局面 |
|---|---|---|
| 英雄 | **两地接应**。整备插两面地表旗，每波可在两旗之间转移一次。代价「交接阵地」要求英雄在出发旗旁交接 1.2 秒，交接一开始就放开正拦着的敌人。 | 溪谷北路的精英刚死，游侠就能赶去南弯补射。骑士若还拦着两只炭狐，可先把兵营旗调到脚下，让士兵接手再走。 |
| 英雄 | **回马一击**。选中自己正拦着的一名敌人，用下一次普攻把它沿原路推回最多 180 像素。这一击放弃普攻伤害。途中撞上同路普通敌人，两者在碰撞处停顿 0.8 秒。 | 森林第 3 波，骑士可以放弃眼前一剑，把走出法师塔射界的苔甲推回去，给塔争取下一轮出手。也可以推炭狐撞住后队，留自己在下游接甲。 |
| 塔与驻军 | **整备换阵**。整备卖塔返 100% 实付金币，开波后锁定建塔、升级、解锁塔位和出售。 | 根据预览整条防线换路。未完的工程照常施工，波中仍可调旗、改炮击点。 |
| 塔与驻军 | **借台齐射**。整备时把两座已完工的弓塔或法师塔相连，供火塔可从接收塔的位置出手。代价是供火塔放弃原塔位整波的射界；接收塔照常射击。 | 溪谷北路现有一座升级法师塔，南路只有一级弓塔。可把法术火力借到南路处理重甲，北弯则要靠人守。 |
| 塔与驻军 | **两营会师**。可以把一座兵营的整队士兵派到另一座兵营的集结旗。调令按整队执行，士兵走完全程才接敌，阵亡者也从本营出发补位。 | 两营可在汇合口摆出两排拦截位。另一条路失守时，撤回三个人要留下真实的行军空档。两营各自保有原人数和容量。 |
| 塔与驻军 | **亲自点名**。英雄普攻命中的第一名非首领精英成为标记。可自动瞄准的攻击塔在射程内优先打它、对它伤害 +60%；精英在射程内时，这些塔会放过更接近核心的敌人。 | 用英雄的第一下普攻决定弓、法师和自动炮塔集火谁。预设落点的炮塔继续守路，改回自动后才跟随点名。 |
| 敌军与波次 | **诱敌合流**。溪谷整备时选南或北，普通主队全部走选中路线。代价「精英绕袭」让本波所有主队精英在开波时同时从另一侧出场。 | 把炮塔和驻军的钱集中押在一路，把另一边的精英留给英雄。第 5 波有 1 只精英，第 8 波有 4 只，到了末波要重新掂量选择。 |
| 敌军与波次 | **定桥迎敌**。遗迹整备时决定西南桥本波始终通短路，或让所有尚未分岔的敌人走长路。代价是本波交战中不能临时用 G 改道。 | 一局把法术塔布在长路吃重甲，另一局让敌人走短路进入核心西侧火网。桥上的人照常先通过。 |
| 核心防务 | **垒墙反推**。每波一次，在各路距核心 120 像素处升起一道共享 300 耐久的墙，最长 10 秒。主动收墙能把贴墙的非首领沿原路推回 100 像素。升墙押上 75 核心耐久，墙未被击破就归还。 | 让前队在墙下聚齐，等炮塔落下一发再收墙，能把幸存者送回火线。若首领紧跟前队，提前收墙可以保住垛石，却要亲自接下后队。 |
| 核心防务 | **烽火齐射**。每波一次，点地表道路上的一个落点，核心在第 2、3、4 秒各打出一发半径 75 像素、70 点法术伤害的烽火弹。开炮露门，从下令到末弹落下的 4 秒内，第一次实际触核额外损失 40 耐久。 | 可照着兵营旗轰被士兵留下的重甲。若另一路快敌已贴近核心，可以把落点改在门前，或先让英雄接住它再开火。 |
| 军费 | **前线悬赏**。整备时可以押 60 金，挑一条路并查看已标出的三名前锋。在各自首次越过预告线前击杀三名（常规道路取半程），立即返押金并另付 80 金。任一越线即失去押金。 | 森林常规开局可把兵和英雄派到半程线前。净赚的 80 金刚好够建一座兵营。若本波要靠后弯守，让这份悬赏留到下波再接。 |
| 军费 | **随军钱箱**。开波前可选一路，把这路前五笔普通主队击杀赏金暂存。随时收箱一次，存满三笔按 1.5 倍领，五笔按 2 倍领。收箱前这路有主队触核，会丢掉整箱。 | 三只炭狐入箱后，可以当场拿 58 金去补阵，也可以继续守住这一路，等五只凑出 130 金买炮塔。另一条路的每次击杀仍照常给钱。 |

**怎样下令。** 接应旗在整备时可重摆，交战中走到旗旁 90 像素内下令。交接进度画在旗下，手动移动、下令出手或倒下即中断，交接中英雄会等候并由驻军接敌，成功到达才用掉次数。回马一击用英雄面板的指令点选目标，预览箭头画到预计碰撞处。出手前目标已脱离拦截就撤销指令。命中占一个正常攻击间隔，六秒后可再用，每个敌人只可被这一招推一次。两个英雄指令都可由永久 1 级角色使用。Q/E 和自动普攻沿用现有输入，自动攻击不会代玩家花掉指令。

### 同一祝福怎么换代价

单向接应要求英雄在甲旗 90 像素内开波，插甲旗会让英雄实际走过去。溪谷的「留一道口」在汇合前只给设防的一路画墙，未指定时默认敞开第一条来敌路。

| 祝福 | 可另配的同类代价 | 这次怎么打 |
|---|---|---|
| 两地接应 | **先遣驻位**。整备时把英雄本人派到甲旗等开波，交战中单向前往乙旗。开波后走位自由，从出发旗发动时立即抵达另一旗。 | 北路首批难守，就把游侠派北，打完再向南接应。若需要从南回北，这一波得自己走。部署前会亮出英雄的开波站位与单向箭头。 |
| 借台齐射 | **交替装填**。供火塔保有本地射界，借台出手后接收塔跳过下一次有合法目标的普通射击；期间无法再次借台。 | 可以照顾两端，代价从放弃北路覆盖改成占用南塔一次出手。接收塔弱、供火塔强时值得换。 |
| 诱敌合流 | **前锋并进**。选中路的前三名普通主队改在其中最早的原定时刻并排出场，精英保留原路与原时刻。 | 前锋同时抵达，原本靠后的两人可能提前，也给了炮塔开局一炮打中三人的机会。预览显示三人的新旧时刻。三人原本同时出场时，跳过此配对。 |
| 垒墙反推 | **留一道口**。整备时在汇合前指定一条有来敌的道路，整波敞开。仅其余路有墙和反推，共用 300 墙体耐久，核心无需出垛石。 | 溪谷可以把墙留给重甲走的路，派英雄守另一路。预览画出两个实际路口。在单路地图或找不到独立城防位置的路段，跳过这一版。 |
| 前线悬赏 | **让出赏金**。用三名前锋的全部基础赏金换签约资格，免押 60 金。按时全歼仍奖 80 金，三人的普通赏金在成功和失败时都已让出。 | 三只普通炭狐合计值 39 金，成功相对正常守线多赚 41 金。手头紧也能接单，若更有把握且钱够，原版押金能挣足 80 金。 |

**什么时候值得发出来。** 两营会师和借台齐射都要求已有相应的两座塔，或眼下有钱、有位置补齐。借台还要有能打到的路段。悬赏从最终队列按出场顺序标记同一路前三名带基础赏金的普通主队，半程线取该路可预知的实际路程。若能临场改道，就把悬赏线画在各走法共用且靠近半程的上游路标，签约后固定。没有这样的路标或当前资金付不起押金时，跳过对应签法。钱箱要有一路至少能存五笔。末波收入要有合法消费窗口。某波缺少对象就照常守线，剩余各波都用不到的牌退出候选。

### 冲突怎么裁决

| 同时发生的事 | 游戏中的结果 |
|---|---|
| 炮塔设了固定落点，英雄又点到精英 | 手动落点优先。仅自动索敌的塔参与标记、享受加伤并承担锁敌代价。末波只剩首领时没有可标记精英，过滤该候选。 |
| 同一座塔被选作两个借台端点，或中途拆走其中一座 | 每座塔同一波只占一个端点。整备拆塔后可以重配；交战中拆掉接收塔，已放弃原射界的供火塔待命至清波。射击沿用供火塔的伤害类型、射程和装填，借的是接收塔的发射位置。额外齐射不能再触发一次借射，已出膛的攻击照常飞行。 |
| 兵营卖出、目的旗挪动或有人想隔河会师 | 外派队沿地表可达路径去目的旗。预览无路就保留原令；在途改旗从当前位置重算。卖掉本营按现有售塔流程撤兵，卖掉接收营则步行回本营。编制和补员始终记在原营。 |
| 敌人被推到分岔或英雄使用接应旗 | 成功推击才解除这名敌人的原拦截。推击和收墙都沿敌人已走过的曲线退行，止于最近经过的岔点或入口。首领和不可推单位不作位移，敌人结束位移后可重新接战。接应旗只设地表，先遣驻位需要英雄在整备时能实际走到出发旗。 |
| 墙、烽火和首领同时到城门 | 墙前的敌人照常受英雄、塔和烽火伤害，留下的敌人攻击墙，首领接触即破墙。墙破先于同刻的主动收墙。默认升墙要求当前耐久大于 75，立即扣押。主动收墙、到时或清波时墙仍在，只退同一笔一次。烽火按每发落点当时的存活目标结算。已死者和被墙挡住者均未触核。真正触核才结算漏损及露门代价，首领先走现有致命触核判定，核心归零立即判负。 |
| 没有精英或东北路仍封闭 | 诱敌＋精英绕袭最早在溪谷第 4 波整备提供，当波须有两路与非首领精英。以后遇到无精英的波次，这组牌整波休息，沿用原排程。支路按开波时开放情况计，破障援兵和召唤沿各自的出场机制加入战斗。 |
| 悬赏、钱箱、全额卖塔同局 | 每个敌人按最终出兵路只记一次基础赏金。「让出赏金」签走的三笔先剔除，钱箱从余下有赏金的普通主队算五笔。押金返还、悬赏奖金和卖塔退款直接进钱包。预览按整组命令重算可用笔数和押金余额。若命令抵触，保留原选择，玩家可在整备内改路或放弃本次签约。 |
| 钱箱与同路漏怪、清波同时结算 | 一两笔按原额，三四笔按 1.5 倍，五笔按 2 倍，整箱向下取整。五笔后其它赏金正常入账。按实际事件顺序处理击杀与触核，同刻先结触核。收箱、失箱或清波自动兑付只结一次，之后本路也照常发钱。单次收箱不会消耗下波机会。 |
| 多项规则同时改路、越线或封工 | 先定实际队列与路线，再发悬赏名单。前锋活着首次到线就判失约，同刻先结已命中的致死伤害。推回线前不能重签。敌人自己的召唤物和事件援兵不顶替签约对象。若新牌会让先前可用的选择在余下整局彻底失效，双向过滤。封工与普通卖塔锁不重复计为两份代价。 |
| 只余一张、没有候选、死亡或重开 | 一轮内祝福不重样，优先未见祝福，选中后保留**当时展示的两面**；剩几张给几张，零张直接整备。英雄复活、重开预览均延续本波命令和次数；重新开一局清空。上一波待发队列、活主队与应处理的首领全部结清后才发下一轮。 |

## 波次与地形

森林常规第 2 波采用 9 炭狐＋2 投矛手，溪谷仅第 5 波的南路晚出 3 秒，遗迹巨像改在第 20 秒出场。遗迹第 5 波按开波瞬间实际开放的道路轮转。东北支路在本波中途开放时，已排好的主队列继续沿原路，破障援兵单独出场。

遗迹的西南长路从分岔到核心多约 739 像素。猎犬多走约 8 秒，重盾傀儡约 19 秒。常规封桥窗口为 14 秒，越过分岔后沿已选曲线行进。溪谷第五波原主队北路 20、南路 6；诱敌能将普通队伍改引到已布防的一路。[道路与波表](../scripts/arena/arena_level_catalog.gd)

## 对照记录

移除营地后的溪谷第五波对照。永久 1 级骑士，种子 60406，固定 60 Hz。每套布阵保持前四波策略一致，仅变更第五波主队路线和精英出场时间。九塔组进波有 102 金，南侧四座二级塔进波有 399 金，六次均守住 750 核心。

| 第五波路线 | 北／南主队 | 双路九塔清波 | 南侧四塔清波 |
|---|---:|---:|---:|
| 依原路 | 20／6 | 23.4 秒 | 55.2 秒 |
| 普通敌走北，精英走南 | 25／1 | 22.2 秒 | 58.1 秒 |
| 普通敌走南，精英走北 | 1／25 | 18.7 秒 | 21.6 秒 |

南侧四塔将普通敌引向南路，比依原路快 33.6 秒。这一组对照的差别体现在清波时间。使用 --lure=base、north 或 south 选择路线，--south-defense 选择南侧防线。[回放脚本](../tests/v020_rule_replay.gd)

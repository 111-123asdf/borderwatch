# 第1周课程归档清单

提交包命名：`04组-第1周-代码仓库.zip`

## 已归档

- 项目源代码、Godot工程配置和必要运行素材。
- README、开发环境、架构、当前玩法、测试和协作规范。
- 英雄、武器、局内成长与全局英雄养成模块。
- 2026-10-29本地验证记录：规则70项、战斗87项、五英雄完整关卡通过。
- 第三方素材来源与许可说明。

## 组长提交前补入

以下内容必须使用课程组真实材料，不能由代码或AI代写事实：

- 立项报告最终审阅版。
- 第1周真实会议纪要（时间、参与者、议题和结论）。
- 第1周四位成员真实周志或汇总周志。
- 第一次作业“面向对象需求分析”的最终提交版（发布后补入）。

建议文件名：

- `04组-立项报告.pdf`或源文档。
- `04组-第1周-会议纪要.md`。
- `04组-第1周-周志.md`。
- `04组-第一次作业-面向对象需求分析.pdf`或源文档。

## 压缩包检查

- ZIP根目录必须包含隐藏目录`.git`。
- 不包含`.godot`、`test-results`、`toolchain`、`builds`和本地编辑器配置。
- 不包含Godot引擎、导出EXE/PCK、原始ZIP、视频、密钥或个人对话。
- 用`git status`确认提交范围，用`git log -1`确认真实作者和提交时间。

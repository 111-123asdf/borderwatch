# 防御塔重做：七塔体系

## 1. 设计目标

竞技场原本只有弩/炮/霜三种塔，塔的升级只是数值放大，塔防卡也只有少量全局加成。重做目标：

- 每种塔有明确职责，不是同一条伤害曲线换皮。
- 每级升级改变行为，至少改变一个使用场景。
- 塔与英雄被动、元素、Build 相互连接。
- 扩大建造半径，让 7 种塔都有放置空间。
- 保持“先选塔，再按同键建造”的操作。

## 2. 七种塔

| 塔 | 定位 | 基础特点 |
| --- | --- | --- |
| 巡林弩塔 | 单体持续 | 高攻速、低单发，升级加穿透 |
| 星火重炮 | 群体爆发 | 溅射、慢攻速，Lv3 附加减速 |
| 寒霜哨塔 | 控场 | 减速、短射程，升级延长控制 |
| 鸣雷弧塔 | 连锁 | 直接弹射多名敌人，升级加跳数 |
| 腐毒藤塔 | 持续伤害 | 中毒 DoT，适合高血/精英 |
| 曜光棱塔 | 穿透直线 | 高弹速、多穿透，适合密集队列 |
| 战地号令 | 支援 | 不攻击，光环提高附近塔伤害 |

## 3. 升级效果

### 巡林弩塔

- Lv2：伤害提高，穿透 +1
- Lv3：伤害提高，穿透 +2

### 星火重炮

- Lv2：伤害、溅射提高
- Lv3：溅射再提高，命中附加 1.2 秒减速

### 寒霜哨塔

- Lv2：伤害提高，减速 +0.5 秒
- Lv3：减速再 +0.5 秒，配合永冻核心可连续冻结

### 鸣雷弧塔

- 每次攻击直接触发连锁
- Lv2：跳数 +1，伤害提高
- Lv3：跳数再 +1
- 雷术卡继续加跳数和伤害

### 腐毒藤塔

- 命中施加 3 秒中毒
- 升级提高中毒 DPS
- 毒术卡继续提高中毒伤害
- 毒伤无视元素弱点，适合处理高血目标

### 曜光棱塔

- 高弹速、高攻速、穿透
- Lv2/Lv3 穿透继续提高
- 棱镜卡提高伤害
- 适合与塔网、指挥协议组合

### 战地号令

- 不攻击
- 260 范围内塔伤害 +10%/级
- 号令卡额外 +5%/层
- 可与堡垒网络、指挥协议叠加
- 自身立即完成建造，不占输出位

## 4. 建造与面积

- 建造半径从 900 扩大到 **1050**
- 建造面板从 3 个按钮扩展为 **7 个按钮，2 行**
- 数字键 **1～7** 对应七种塔
- 第一次按数字只显示塔影，第二次同键才建造
- 换数字切塔
- 右键取消
- 塔上限仍为 10

## 5. 塔防卡

基础：

- 弩术：弩塔攻速
- 炮术：炮塔伤害/溅射
- 霜核：霜塔减速/范围
- 雷术：电弧塔伤害/跳数
- 毒术：毒塔中毒伤害
- 棱镜：曜光塔伤害
- 号令：战旗光环
- 塔链：全塔伤害
- 塔网：2 格内塔伤害
- 塔防指挥：英雄附近塔伤害
- 工程学：建造/升级费用

进化：

- 堡垒网络：塔网 + 塔链
- 超载炮击：弩术 + 炮术
- 永冻核心：霜核 + 塔网
- 指挥协议：塔防指挥 + 工程学

## 6. 验证目标

- 7 种塔都能建造并实际攻击/支援
- 每种塔的 Lv2/Lv3 至少有一个行为变化
- 战旗光环能被塔面板看到
- 七塔建造菜单可用数字键 1～7
- 三英雄自然经济仍能通关
- 4 塔失败边界下一轮复测

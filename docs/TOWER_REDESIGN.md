# 防御塔重做：七塔体系

## 1. 设计目标

竞技场原本只有弩/炮/霜三种塔，塔的升级只是数值放大，塔防卡也只有少量全局加成。重做目标：

- 每种塔有明确职责，不是同一条伤害曲线换皮。
- 每级升级改变行为，至少改变一个使用场景。
- 塔与英雄被动、元素、Build 相互连接。
- 扩大建造半径，让 7 种塔都有放置空间。
- 保持“先选塔，再按同键建造”的操作。

## 2. 七种塔

| 塔 | 定位 | 基础特点 |
| --- | --- | --- |
| 巡林弩塔 | 单体持续 | 高攻速、低单发，升级加穿透 |
| 星火重炮 | 群体爆发 | 溅射、慢攻速，Lv3 附加减速 |
| 寒霜哨塔 | 控场 | 减速、短射程，升级延长控制 |
| 鸣雷弧塔 | 连锁 | 直接弹射多名敌人，升级加跳数 |
| 腐毒藤塔 | 持续伤害 | 中毒 DoT，适合高血/精英 |
| 曜光棱塔 | 穿透直线 | 高弹速、多穿透，适合密集队列 |
| 战地号令 | 支援 | 不攻击，光环提高附近塔伤害 |

## 3. 升级效果

### 巡林弩塔

- Lv2：伤害提高，穿透 +1
- Lv3：伤害提高，穿透 +2

### 星火重炮

- Lv2：伤害、溅射提高
- Lv3：溅射再提高，命中附加 1.2 秒减速

### 寒霜哨塔

- Lv2：伤害提高，减速 +0.5 秒
- Lv3：减速再 +0.5 秒，配合永冻核心可连续冻结

### 鸣雷弧塔

- 每次攻击直接触发连锁
- Lv2：跳数 +1，伤害提高
- Lv3：跳数再 +1
- 雷术卡继续加跳数和伤害

### 腐毒藤塔

- 命中施加 3 秒中毒
- 升级提高中毒 DPS
- 毒术卡继续提高中毒伤害
- 毒伤无视元素弱点，适合处理高血目标

### 曜光棱塔

- 高弹速、高攻速、穿透
- Lv2/Lv3 穿透继续提高
- 棱镜卡提高伤害
- 适合与塔网、指挥协议组合

### 战地号令

- 不攻击
- 260 范围内塔伤害 +10%/级
- 号令卡额外 +5%/层
- 可与堡垒网络、指挥协议叠加
- 自身立即完成建造，不占输出位

## 4. 建造与面积

- 建造半径从 900 扩大到 **1050**
- **取消塔数上限**：不再受 10 座塔限制，只受金币、地形、路径和 8 邻接规则约束
- **B 进入/退出建造**
- **鼠标滚轮切换塔型**，也可以用数字键 1～7 直接选
- 选塔后显示半透明塔影
- **鼠标左键确认放置**
- 右键取消
- 选塔时不占用数字键连按，左键就是唯一确认动作

## 4.1 选塔信息面板

建造模式下，塔影旁显示当前塔的完整信息：

- 名称、造价
- 定位（单体/群体/控场/连锁/持续/直线/支援）
- 基础伤害
- 射程、攻击间隔
- 特性说明（例如“范围霜爆，叠冻气冻结”）
- 操作提示

不再用 7 个只写名字和价格的按钮；滚轮切换时信息即时更新。

## 4.2 攻击方式区分

| 塔 | 实际攻击方式 |
| --- | --- |
| 弩塔 | 发射弩箭，Lv3 三连齐射并穿透 |
| 重炮 | 抛射爆炸，范围伤害，Lv3 减速 |
| 霜塔 | 在目标点引发**范围霜爆**，不是子弹 |
| 电弧 | **直接连锁**多个目标 |
| 毒塔 | 在目标点释放**毒云**，范围中毒 |
| 曜光 | **瞬时光束**贯穿直线上的敌人 |
| 战地号令 | 不攻击，持续光环 |

## 4.3 目标与操作

- 塔可切换目标优先级：**最近 / 最强 / 最前**
- “最前”按离核心距离选目标
- 塔面板显示当前射程、攻击间隔、目标模式
- 塔面板支持 **拆除**，返还 60% 基础造价 + 等级加成
- 每级升级会提高射程和攻速

## 5. 塔防卡

基础：

- 弩术：全塔攻速 +4%，弩塔再 +10%
- 炮术：全塔伤害 +5%，炮塔再 +15%/溅射
- 霜核：全塔射程 +8，霜塔再 +0.5 秒减速
- 雷术：全塔伤害 +4%，电弧塔再 +15%/跳数
- 毒术：全塔伤害 +5%，毒塔再 +15% 中毒
- 棱镜：全塔射程 +8，曜光塔再 +10%
- 号令：战旗光环额外 +5%
- **混编：每种不同塔使全塔伤害 +4%**
- 塔链：全塔伤害
- 塔网：2 格内塔伤害
- 塔防指挥：英雄附近塔伤害
- 工程学：建造/升级费用

设计目的：**专精卡不再只对某一种塔生效**，即使玩家没建该塔，也能吃到全塔部分，避免“只建一种塔才能吃到所有加成”。

进化：

- 堡垒网络：塔网 + 塔链
- 超载炮击：弩术 + 炮术
- 永冻核心：霜核 + 塔网
- 指挥协议：塔防指挥 + 工程学

## 6. 验证目标

- 7 种塔都能建造并实际攻击/支援
- 7 种塔的攻击方式不同：弩箭、爆炸、霜爆、连锁、毒云、光束、光环
- 每种塔的 Lv2/Lv3 至少有一个行为变化
- 战旗光环能被塔面板看到
- 滚轮/数字选塔，左键确认
- 专精塔防卡同时提供全塔收益
- 混编卡按塔种类数提供全塔伤害
- 三英雄自然经济仍能通关
- 4 塔失败边界下一轮复测

测试：`tools/verify_arena.ps1`。

# 第一关：森林边哨

## 场景与气氛

森林边境的遗迹核心仍在发光，敌人从林地四周逼近，英雄和防御塔一起守护它。用青色信标、暖铜和森林木石统一核心、塔、界面和营地；开场用画面传达守护的故事，文字保持简短。

以 `feature/arena-survival-prototype` 竞技场为玩法基线：保留环形出怪、波次、自由建塔、英雄技能、弹幕和现有被动系统。这里的美术设想不代表改动了战斗或已完成后续系统。

## 推进顺序

- 完善森林地表、障碍与营地的形状和细节，让装饰不遮挡敌人、预警和放塔位置；检查障碍外观与实际阻挡是否一致。
- 先做一个英雄和一种敌人的待机、行走、攻击、受击样板，确定像素尺寸、朝向与持武器位置，再推广到其他角色。
- 为各类防御塔、武器、敌人和被动选择制作统一且易辨认的外观；建塔交互围绕竞技场的自由格子规则设计。
- 逐步统一英雄选择、引导与后续局外界面，保持战斗画面简洁，真人试玩后再决定节奏和细节。

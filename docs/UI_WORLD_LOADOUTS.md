# 世界地图与出战配置 · v0.10

本次以负责人提供的约51秒录屏为交互参考：标题画面、地图底部功能入口、独立英雄配置与关卡侧面板。原视频和其中的商业素材不进入工程资源。图像使用内置生成工具重新制作，记录见ART_GENERATION_V010.json。

## 世界与界面

大陆具有森林、雪山、荒地、遗迹等不同地貌，当前两个可玩节点都在森林区域。其余地貌只提供世界背景，不放假关卡或无功能按钮。通用材料是石木、皮革、羊皮纸和金属，管理场景是中性前哨庭院，后续地区可使用自己的地图和故事。

标题只保留标题图、开始、设置与退出。世界默认显示地标、资源、配置摘要和底栏；关卡面板靠边，文字限定短关卡名与必要数字。英雄和塔的详细说明使用悬停，成长图鉴点卡查看。动画为轻微环境粒子、悬停反馈、按压回弹和200毫秒切换；减少动态关闭粒子与缩放，保留短淡入。

## 导航与配置

标题→世界→关卡→出战。英雄页浏览角色不会修改出战配置，点击出战才替换唯一英雄槽。等级和技能规则沿用现状。塔页最多四槽，至少保留一类，可装卸及预览三级；真正升级与改造留在局内。图鉴展示现有40卡与联动，无永久被动树。返回保留页面浏览选择，Esc优先关闭侧面板/当前层，子页回地图；世界Esc打开设置。

关卡要求至少有一类首波可建塔。未满足时显示配置入口，进塔页修复后即可出战。局内只显示已装备塔，未到开放波次的塔仍锁定；开局快照配置，重开沿用快照。

## 保存与扩展

campaign_v3.cfg新增selected_hero和equipped_towers，缺字段的旧档内存补默认；加载不写盘，配置保存沿用临时文件加rename。失败不改变原配置和养成。正常用户档与旧训练档不清理。

新增关卡在ArenaLevelCatalog登记ID与WORLD_NODES，并配置world_region、biome、story、map_art及可选preview_art。世界节点不决定战场道路，战场道路/塔位仍须通过原布局检查。单存档、当前两关直接可玩；本轮不增加商店、成就、剧情过场或第二个运行工程。

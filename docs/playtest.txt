边境守望 · 核心切片预览（由0.3派生）

运行 Borderwatch.exe，无需安装Godot。主菜单可进入英雄养成、玩法引导或开始游戏；进入边境林地前从五位英雄中选择一位，单局中不能切职业。

操作
WASD / 方向键：移动，随时打断鼠标行军。
左键 / 按住左键：攻击；自动锁定射程内最近、未被掩体挡住的敌人。
鼠标不用瞄准，自动索敌不替你追怪；没有目标时沿面向攻击。
右键地面：行军；也可先点英雄再点目的地，或拖动英雄到目的地松开。
Space / C：同一个英雄专属技能，不是两个技能。没有通用闪避。
Q：在两把武器之间切换；数字1 / 2直接选择对应武器槽。
点击路边圆形空地：选择建塔；点击已有塔：升级 / 出售。
E：已肃清的宝匣 / 解救伙伴；再次在已开启宝匣旁按E，沿捷径回营。
Tab：暂停打开双武器栏与成长。
R：2.2秒引导回营；移动、攻击或受伤打断，完成后冷却28秒。
F：开波。首波90秒后自动开始，也可手动确认提前；之后清场有55秒准备，提前开波不加钱。
M：暂停地图。Esc：暂停、操作与设置。

英雄
曙光骑士：120血 / 70盾 / 100能量，移速265。
  火力双生：12秒冷却、持续5秒，临时复制当前武器；第二把消耗相同能量。
  没有翻滚或技能无敌，依靠走位、护盾，换近战也可消弹。
林影游侠：85血 / 45盾 / 110能量，移速305。
  掠影翻滚：1.8秒冷却，沿移动方向滚动约0.22秒，短暂无敌。
  只有这位英雄能翻滚；停步时沿面向滚动。
星纹秘术师：75血 / 65盾 / 180能量，移速280。
  星纹结界：14秒冷却、持续3.5秒，拦截近身敌弹并回能；不能挡近战与红圈。
燧石机巧师：92血 / 58盾 / 145能量，移速275。
  超载核心：11秒冷却，恢复护盾与能量，4秒内武器攻速提高35%。
裂阵先锋：108血 / 52盾 / 115能量，移速285。
  震荡新星：9秒冷却，伤害并击退近身敌人，同时清除周围敌弹。

武器
所有英雄都以铜雀手枪和曙光长剑起步。探索武器在营地宝匣里获得，会替换副槽并自动装备，原当前武器仍可切回：
  苔石林地 = 群星法杖（散射清群）
  回响石庭 = 远星狙击（直线穿透点杀）
  沉星深殿 = 回风月轮（往返伤敌、接触消弹）
武器等级由宝匣顺序决定，没有单独的强化商店。

建议体验路线
1. 选择英雄，180金先建一座100金弩塔；利用90秒准备期清首营地拿120金，再补另一侧防线。
2. 跟随顶部指引探索东北苔石林地：一场遭遇，清完开宝匣拿法杖。
3. 木箱 / 石墙能挡子弹和行军。绕侧面射击，不要一直隔墙空射。
4. 宝匣旁再按 E 沿捷径回营。
5. 回防开波。塔守双路，英雄补关键敌人；清营地会让你二选一一条路线。
6. 一波后探索回响石庭拿狙击；三波后探索沉星深殿拿月轮。
7. 每个营地只有一个节点：走得到、打得完、拿得到。
8. 用弩塔与重炮守住第六波，击败焚林统领。

关键规则
普通攻击塔不受敌弹 / Boss红圈伤害，英雄不能入驻塔避弹。
敌人沿路突破伤核心；Boss抵达核心直接失败。英雄倒下扣20核心，4秒复归。
核心不会自行修复：漏一只怪就是一笔账。
护盾脱战3.2秒后每秒恢复16；能量自动恢复。
红色弹幕有留缝环、间隔扇形齐射与弧线弹；红圈预警后爆发，需要移动离开。
击杀、宝匣与清波发金币；建塔与升级共用金币，没有生产建筑。
路线只在清营地时二选一，选定即锁定（防线 / 主力 / 节奏 三组各一次）；英雄升级增加生命、护盾、能量和伤害。
局内等级每局重置。结算按波数、英雄击杀和胜负发放全局经验；全局升级获得的点数在主菜单“英雄养成”中永久强化属性。
暂不加入长期养成、第二关或退出后的单局存档。

# 当前素材与来源
当前运行资源为assets/v06/*.png及assets/original/frontier_menu_button.png。所有当前图片使用OpenAI内置imagegen为本项目生成；仅有PNG输出，不声称具备手绘逐层源文件。

三张portrait为英雄选择立绘。九张knight/ranger/mage的side/down/up表，每张六列七行，顺序为待机、移动、普攻、小技能、大招、受击、倒下，专属武器已画入完整人物。早期白发长袍、精细日漫场内人物及过度简单的方向草稿未随当前工程保留。骑士与游侠立绘分别参考负责人提供的骑士、游侠表情和动势，法师参考大帽女巫的活泼施法姿态，服装与构图重新设计。

七张creature表为炭狐、苔甲、幽光、投矛手、孢囊兽、飞蛾及士兵，六列三行，分别走动／攻击／倒下。保留项目前期生成的森林生物种类，重新生成完整序列，不恢复最初的占位怪。透明底提取也通过imagegen完成。

towers.png为四列三行，四列依次弓箭塔、法师塔、火炮塔、兵营，三行依次一级至三级，共十二套建筑形态。props.png为四列两行的树、岩、遗址、营地与信标。map_forest与map_creek从经过规则检查的1600×900布局图生成，保留道路、塔位和营地位置；溪谷双路不镜像，桥位错开。实际通路、碰撞、射界仍以ArenaLevelCatalog与检查为准。

生成提示词和最终输出记录见ART_GENERATION.json。该文件记录内置工具模式、选定图与提示，不包含临时生成失败稿或私人聊天记录。负责人提供的17张商业游戏立绘参考保存在工程外的美术参考，公开实机与攻略只供构图、比例、动作研究，不直接打进成品。研究链接见MOTION_ART_DIRECTION.md。

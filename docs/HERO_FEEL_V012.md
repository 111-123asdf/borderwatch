# v0.12 · 游侠与法师表现推广

负责人认可青年骑士小样后，本轮把同一绘制语言推广到森林游侠与星纹法师。骑士资产不改动；四塔、关卡、卡牌、货币、永久养成和战斗数值不扩充。源码仍为唯一正式工程，未代负责人提交或上传。

## 设计与动作

游侠为栗色短发青年男性、绿披风、皮甲和长弓，轮廓轻快；法师为紫色短发青年女性、大帽、米白紫袍和星杖，轮廓偏竖向。共同使用利落描边、有限明暗色块和约3.5头身，保留不同职业的服装、站姿与攻击形状。不是三张换色皮肤，也不宣称真实3D模型。

每位英雄研究9项外形、连续动作或实机参考，取舍见ART_GENERATION_V012.json；本机图板在工程外“美术参考/英雄研究-v012/参考板.html”。商业图和作者公开预览只研究姿势、层级、比例，不放进运行或源码包。原始生成PNG保留，tools/build_hero_regions.py仅分析透明轮廓、脚底与出手点，生成元数据，不改写图像。

每英雄3方向×7状态×8个生成关键姿势=168姿势；播放仍为6/8/10/10/12/4/6帧，包含保持和复用，不夸称每个播放帧都是独立中间画。待机、走路、普通攻击、小技能、大招、受击、倒下分别接入。脚底统一到虚拟画布(128,240)，视觉约1.3倍；碰撞半径12、攻击射程、拦截容量保持。

| 动作 | 预备→出手→恢复 | 实际规则 |
| --- | --- | --- |
| 游侠普攻 | 装箭、拉弓与肩肘回收→短促松弦→弓回弹 | 第6播放帧发射；每第三箭沿用额外贯穿一目标 |
| 游侠翻滚 | 压低重心→完整身体翻转→撑起恢复 | 位移与保护从按键开始；不等晚出手帧才生效 |
| 万叶箭雨 | 举弓蓄势→向上放箭→收弓 | 保留6段，.4秒后首段，间隔.32秒，半径135 |
| 法师普攻 | 聚能、肩臂抬起→星杖亮起并发射→收势 | 第5播放帧发射；魔法弹沿用追踪与易伤 |
| 寒星霜环 | 收拢手势→向外展开→回到持杖 | 半径125，魔法伤害与3秒减速；没有额外冻结 |
| 星陨 | 举杖引导→指定位置落星→收势 | 出手后.85秒命中、半径155；原有1.2秒眩晕保留 |

帧事件与低帧率时钟后备共用ArenaMotion.release_fraction，只释放一次。移动能取消恢复，不能重置攻击冷却。箭从松弦姿势的弓口、星弹从法器发出，侧向镜像同步翻转。投射物保存来源标签，飞行后不依赖当前英雄动作猜命中类别。伤害类别继续由真实damage_type决定：暖色箭形为物理，紫色星形为法术。塔弹、敌弹保持原路径。

命中沿用局部闪亮、挤压和分类型数字；星陨可短暂停顿受击目标的动画，不冻结已做其他动作的施法者。密集命中仍限制震屏频率；不修改全局时间。减少动态关闭震屏与局部动画停顿。特效透明底通过imagegen重做，不以浅色矩形遮住战场。

## 音效和实验入口

新增11个CC0采样提示，约81KB：取箭、箭羽、布料、木质接触、铃/碎晶与冰法术。音效按开始聚能、实际出手和命中分别触发；只分发选中的OGG。完整原文件名、处理、作者、许可、SHA256见AUDIO_V012.json，声明在third_party/hero_audio_v012。弓声是采样拟音，不虚称实录弓弦。

外层“英雄手感实验.bat”和旧“骑士手感实验.bat”打开同一EXE的--feel-lab；可切三个英雄、原版、尺寸、减少动态、重置敌人和双技能。可加--lab-hero=ranger或mage。每次切换新建不持久化5级夹具，CD、金币、击杀不串；返回地图重新读取原存档。修复实验场跳过波次时也跳过延迟技能结算的问题，箭雨和陨星现在可以完整命中。正常游戏规则不变。

## 验证边界

v012_feel检查元数据、出手镜像、单次释放、贯穿、实际伤害类型、音频和实验场延迟命中；v012_lab_cli用隔离的已有档逐字节检查切英雄和返回不改存档；v012_window通过真实窗口事件检查两尺寸的头像、三英雄切换、技能、对照与按钮范围。完整回归、成品通关、压力数据和实际录屏结果写入RELEASE_NOTES.md。

技术检查不能证明主观手感已经被认可。游侠/法师的最终审美和操作舒适度仍由负责人试玩反馈确认，不伪造真人盲测。

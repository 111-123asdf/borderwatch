# 视觉规范 v2 · 骑士认可后推广

目标是画面统一、主体清楚、动作可读。统一绘制语言，不统一所有地区的地貌和色调。当前v0.10画面仅作旧版对照，不能当作新规范已通过的样板。

## 世界与通用界面

世界允许森林、雪山、荒地、遗迹各有色彩和光照气氛；现阶段只打磨现有两关。通用界面采用中性石木、皮革、金属、羊皮纸。浅底正文使用深褐#49321f，深底文字使用米白#f2e4c5，暖金#e9c588只用于当前主要动作和强调，不给每个图标套同样的抢眼金框。

每屏确定一个视觉焦点和一个主要动作。世界未开放地区保留地貌区别，通过低对比/云雾降低层级；只为真实可玩内容放入口，不新增虚构星级规则。先用已有通关状态表达路线与旗帜。

标题图、按钮、地标周围留安静区域，背景不处处等强度。技能和成长图标要能表现具体内容；同屏的新缩略图、头像、敌人图标须匹配手绘/塑形的材质、轮廓和细节密度。先替换一组小样，认可后再批量。

## 角色、建筑与特效

骑士首批样板按负责人最新反馈改为青年、露面、短发、利落卡通轮廓和有限明暗色块，放弃旧头盔厚甲的大叔感与写实金属堆砌。负责人已认可骑士小样，v0.12推广到青年男性游侠与青年女性法师，仍需分别试玩确认。

常态受光以左上主光为基准，脚底阴影与接触面稳定；不把透明外边距当角色尺寸。轮廓以实际窗口可读为准，不强行给每个物体加同样粗描边。

三英雄测试视觉放大约1.3倍，记录两个窗口尺寸下的真实占高和路面遮挡。碰撞、射程和拦截规则不随视觉自动放大；武器仍与身体动作保持一体。

动作必须能辨认预备、接触、恢复。关键姿势之间有重心与肢体变化；整图抖动、缩放、旋转不代替走路或挥砍。伤害与出手帧同步，移动取消恢复不重置冷却。

塔的底部接触中心与升级占地稳定。建造、升级、开火反馈不移动塔位或碰撞；可动机关单独表现。地表接缝、道具方形色差、轮廓白边逐个检查。

物理以暖金/橙白切削火花表达，法术以蓝紫/青白能量表达，结合弹体轮廓和图标，不单靠颜色区分。敌方预告优先红橙，范围清晰且与判定一致。重要命中更强，普通攻击不持续震屏。动态不能遮挡道路、敌弹、基地或关键按钮。

## 字体、布局与动态

标题展示字体与正文家族各限一套，使用前核对具体字体文件的分发许可。正文先以明确字重和对比度保证可读；描边/投影按背景使用，不给浅纸上的正文强加同样重的外描边。

以1600×900和1024×576为验收窗口；新关键点击区至少44实际像素，普通标签至少14实际像素，伤害数字单独在实机中核对。图标与数字分区排布，费用不能盖住按钮文字。详细说明按需打开。

悬停1.05、按压0.95、切换200—300ms作为初始动效参数，保持短而可取消。不规定每屏必须凑三个会动的物件；动态要服务关注点。减少动态模式关闭环境漂移、强缩放、推近和震屏；闪烁采用温和替代。

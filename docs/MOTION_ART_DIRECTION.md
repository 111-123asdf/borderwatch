# 动作与视觉制作标准 · v0.9
本轮按负责人最新反馈调整为精致塑形、柔和体积光的2D精灵，不宣称真实3D模型。英雄约80—84像素高度，年轻、轮廓清楚、专属武器与人物一体。骑士银蓝甲与红披风、游侠绿兜帽与青围巾、法师大帽与紫袍分开辨识。

待机6帧、移动8帧、普攻10帧、小技能10帧、大招12帧、受击4帧、倒下6帧，三方向共504个播放帧。每张12×7源图中按状态采样完整姿势序列；侧向可镜像。ArenaMotion统一各帧相对时长，前摇较稳、接触较快、后摇舒展。普通近战/法术在索引5释放，游侠普攻和大招在索引6释放；时钟后备由同一权重求释放比例，低帧率也只触发一次。骑士压低重心后斩出，游侠拉弓再松弦，法师聚能再释放。移动可取消恢复阶段，冷却继续计时。

地表已清除旧烘焙塔环，空塔位与建成建筑在同一接触中心。四类三级建筑共用96×48地基占地；升级长高、增加机关结构，不移动根部。接触阴影短而贴地，建筑在脚底排序层中；开火光效与弹体从实际发射位置出现，禁止整座建筑摇摆。

移动约80毫秒起步、约40毫秒停步。动画步频与移动速度相配，避免腿慢脚快；炭狐快步、苔甲沉步，幽光漂浮和飞蛾振翅独立。脚底锚点与影子保持接触。普通受击、重击、技能与击杀的反馈逐级增强，密集命中不冻结全场。

每个角色先检查侧向走路、一次普攻与一次技能的连续播放，再扩展三方向七状态。验收看真实场景和短动画，静态立绘漂亮不能代替动作验收。不要给整张角色图片套循环上下弹跳冒充步态；关节姿势、躯干重心和武器必须在帧中共同改变。

# 动作与视觉制作标准 · v0.6
本轮按负责人最新反馈调整。立绘表现人物性格与姿态，场内动作须在60—70像素角色高度下仍然清楚；同一英雄共用服装、发色与武器标志。骑士银蓝甲与红披风、游侠绿兜帽与青围巾、法师大帽与紫袍分开辨识。

普攻有预备、接触、恢复三个阶段。ArenaMotion统一配置六帧相对停留时间，并由相同权重计算实际释放时点；伤害不从按键瞬间发出。骑士重心下压后快速斩出，游侠拉满弓弦再松开，法师举杖聚能后释放。恢复阶段可通过移动取消，冷却仍继续，不能通过取消动作加快攻击。

移动约80毫秒起步、约40毫秒停步。动画步频与移动速度相配，避免腿慢脚快；炭狐快步、苔甲沉步，幽光漂浮和飞蛾振翅独立。脚底锚点与影子保持接触。普通受击、重击、技能与击杀的反馈逐级增强，密集命中不冻结全场。

每个角色先检查侧向走路、一次普攻与一次技能的连续播放，再扩展三方向七状态。验收看真实场景和短动画，静态立绘漂亮不能代替动作验收。不要给整张角色图片套循环上下弹跳冒充步态；关节姿势、躯干重心和武器必须在帧中共同改变。

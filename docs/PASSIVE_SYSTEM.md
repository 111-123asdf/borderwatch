# 升级被动系统：向《黎明前20分钟》学习后的重构方案

## 1. 参考对象拆解

《黎明前20分钟》的升级不是“每次三张 +5% 数值卡”，而是**围绕当前武器、元素和生存路线做 Build**。可复用的设计原则：

- **三级卡池**：武器/弹道改造、元素附着、生存与经济。
- **三选一 + 稀有度**：普通、稀有、史诗；高稀有度不是纯数值，而是规则变化。
- **叠层有上限**：同类升级可以重复拿，但有 max stack；卡面显示 `已拥有/上限`。
- **武器身份**：手枪、弓、散弹有各自的专属升级，不同武器在同一个池里拿到的核心卡不同。
- **元素协同**：火、冰、雷不是独立增伤，而是能互相触发；满足条件后出现“进化/协同”卡。
- **承诺成本**：一次只能拿一张，三选一决定这一局是弹幕、元素、召唤还是生存路线。
- **重掷/放逐**：20MTD 类游戏用重掷降低“三张都不想要”的挫败感；本作先做有限重掷。
- **卡面信息**：名称、稀有度、标签、当前层数、上限、规则说明，而不是只有一句 +25%。

## 2. 当前竞技场被动的问题

1. 所有英雄共用 21 张卡，武器差异只体现在面板伤害，升级不改变武器玩法。
2. 大量卡是纯百分比：过载、速射、致命、体魄、重盾；三张卡经常只是数值不同。
3. 没有叠层上限和卡面层数，玩家不知道“再拿一次会怎样”。
4. 协同只有“连锁/霜环/处决”等零散规则，没有明确的元素组合目标。
5. 升级池和营地宝匣几乎同池，宝匣的“强力”只体现在免费，不体现在稀有度。
6. 没有重掷，三张都不合 build 时只能硬选。

## 3. 新结构

### 3.1 卡牌字段

每张卡有：

- `name`：中文名
- `desc`：一句话规则
- `rarity`：`common` / `rare` / `epic` / `synergy`
- `tags`：弹道、元素、生存、经济、塔防、武器、协同
- `max`：最大层数
- `weapon`：限定武器（空为通用）
- `requires`：协同前置被动
- `pool`：`both` / `level` / `camp`

### 3.2 三层卡池

| 层 | 示例 | 作用 |
| --- | --- | --- |
| 武器/弹道 | 手枪口径、双持弹匣、猎弓、散弹加弹 | 改变当前武器的输出方式 |
| 元素 | 燃烧、霜附、连锁、霜环、雷暴 | 提供触发与清群 |
| 生存/经济/塔防 | 体魄、重盾、疾行、贪婪、博学、塔链 | 保证能活到成型 |

升级三选一以武器卡和元素卡为主；营地宝匣只出 **rare / epic / synergy**，作为中期 build 定型点。

### 3.3 协同/进化

满足前置后，协同卡进入卡池：

- **燃烧 + 连锁 → 雷火**：连锁命中引发燃烧爆炸。
- **霜附 + 致命 → 碎冰**：暴击冻结目标并额外伤害。
- **处决 + 致命 → 行刑者**：处决阈值从 35% 提高到 50%。
- **雷暴 + 霜环 → 风暴眼**：雷暴落点再触发霜环。
- **吸血 + 尸爆 → 收割**：尸爆回复生命。
- **塔链 + 专注 → 塔防协议**：塔伤害提高，技能冷却缩短。

协同卡是 `max=1` 的 build 终点，不应在前期大量出现。

### 3.4 稀有度与权重

- common：60
- rare：30
- epic：10
- synergy：满足前置时 45（出现一次后不再出现）

同时保证：

- 不出现当前层数已满的卡；
- 不出现不符合当前武器的专属卡；
- 三张不重复；
- 每次升级至少保证一张“当前武器或元素”卡（后续实现）。

### 3.5 UI

- 卡面左上显示稀有度颜色，右上显示 `层数/上限`。
- 标签行显示“弹道 / 元素 / 武器”。
- 协同卡显示“协同”标签和前置。
- 保留“先选卡，再确认”，避免误触。
- 增加一次重掷（后续接入）。

## 5. 实现顺序

1. `ArenaUpgrades` 数据类：字段、稀有度、武器过滤、前置过滤、加权三选一。
2. `ArenaGame` 升级/宝匣改走新池；`passive_info` 返回层数/上限/稀有度。
3. HUD 卡面显示稀有度、标签、层数；保留确认机制。
4. 首批规则效果：燃烧、过载、塔链、减速增伤、碎冰、雷火。
5. 回归：三英雄自然通关；升级/宝匣/暂停/重开不回归。

## 6. 平衡原则

- 纯数值卡总增益控制在 10%～20%/层，规则卡优先。
- 协同卡出现后应明显改变清群方式，而不是再 +20%。
- 营地宝匣只出 rare+，让宝匣成为 build 拐点。
- 每局至少能拿到 1 张武器专属卡和 1 张元素卡；不能三张全是经济。
- 先保证 3 英雄都能通关，再提高敌人压力；不靠堆怪掩盖 build 深度不足。

## 7. 首版落地状态（2026-10-25）

- 已新增 `ArenaUpgrades` 数据类：**81 张卡**，含稀有度、标签、max stack、武器限定、职业限定、协同前置、加权三选一。
- **跨塔群增益**：弩术/炮术/霜核/雷术/毒术/棱镜都同时提供全塔收益，混编卡按不同塔种类数加全塔伤害，避免“只建一种塔才不浪费被动”。
- **七塔体系**：弩/炮/霜/电弧/毒藤/曜光/战地号令；每座塔 3 级，升级改变行为；塔防卡与进化见 [TOWER_REDESIGN.md](TOWER_REDESIGN.md)。
- **元素交互**：霜附叠 3 层冻结 1 秒（深寒改成 2 层并延长）；野火让燃烧敌人死亡时传播火焰；导电让连锁/雷暴对燃烧或减速目标 +40%。
- **塔防进化**：堡垒网络（塔网+塔链）、超载炮击（弩术+炮术）、永冻核心（霜核+塔网）、指挥协议（指挥+工程学）；塔面板会显示对应进化。

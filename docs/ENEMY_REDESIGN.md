# 怪物与出怪重做

## 问题分析

旧版出怪与怪物存在四个结构性问题：

1. **固定点出怪**：8 个固定 spawn 点，怪物从同一点以矩形抖动出现，路线可预测。
2. **攻击目标单一**：除自爆兵外，大部分怪物只沿路径打核心，不会锁定塔或英雄。
3. **怪物类型差异小**：多数怪只是血量/速度变化，攻击方式仍以接触和少量子弹为主。
4. **精英只是数值放大**：精英没有词缀、没有可识别的行为，Boss 阶段也只召唤。

重做方向：

- 出怪从固定点改为**环形高斯分布 + 阵型**。
- 怪物按角色分工：攻城、猎杀英雄、远程、治疗、分裂、自爆。
- 精英获得**词缀**。
- Boss 阶段与塔防联动。
- 不再用固定点，改成概率区域 + 预警圈。

## 出怪方式

### 高斯环形采样

每个区域仍有一个中心角，但实际落点：

```
angle  = 区域中心角 + 高斯(0, sigma_angle)
radius = SPAWN_RADIUS + 高斯(0, sigma_radius)
```

- 默认 `sigma_angle = 0.30`，`sigma_radius = 90`
- 点会落在环形林线附近，不固定在同一点
- 自动寻找最近可行走格
- 不会刷在塔、障碍或核心内

### 阵型

每批怪随机选择：

| 阵型 | 特点 |
| --- | --- |
| 集群 | 中等角度、较宽半径，常规压力 |
| 纵列 | 窄角度、小半径，沿一条线压进 |
| 钳形 | 两个相对区域同时出现，迫使分兵 |
| 散兵 | 大角度、大半径，覆盖面广 |

### 预警

- 每个阵型先生成橙色预警圈
- 预警约 0.62～1.0 秒后才真正出怪
- 预警圈持续约 1.2 秒
- 小地图同步显示预警位置
- 不再用固定 spawn 点圆点

## 攻击锁定与可读性

- 工兵/自爆兵/迫击兵锁定塔后保持目标，超过 520 距离才重新找
- 冲锋兵/猎犬锁英雄，显示橙红细线
- 迫击兵开炮前 0.45 秒画攻击环，命中延迟
- 自爆兵贴身时先画 0.45 秒引爆环，再爆炸
- 锁定线和攻击环让玩家能判断“它现在要打谁”

## 怪物种类

| 怪物 | 角色 | 攻击/行为 |
| --- | --- | --- |
| 火炬手 | 基础 | 沿路径冲核心，接触英雄 |
| 桶兵 | 基础 | 高血、慢速，接触英雄 |
| 弓手 | 远程 | 保持距离射击英雄 |
| 冲锋兵 | 猎杀 | 锁英雄，高速冲锋 |
| 猎犬 | 猎杀 | 更快、更脆，锁英雄 |
| 自爆兵 | 攻城 | 锁定附近塔，贴身爆炸，伤害塔和英雄 |
| 工兵 | 攻城 | 锁定塔，持续拆塔 |
| 重装兵 | 坦克 | 高血，核心压力 |
| 盾兵 | 坦克 | 高血，闪电弱点 |
| 铁甲兵 | 坦克 | 最高血，闪电弱点 |
| 萨满 | 支援 | 周期治疗附近怪物 |
| 迫击兵 | 攻城 | 远程炮击塔，保持 240 距离 |
| 分裂体 | 特殊 | 死亡分裂成两只猎犬 |
| 焚林统领 | Boss | 阶段召唤、冲击波静默塔、核心攻击 |

### 弱点

- 猎犬/冲锋/自爆/工兵：冰
- 弓手/迫击/盾兵/铁甲：雷
- 重装/萨满/分裂：火
- Boss：冰（Boss 会按玩家主元素自适应）

## 精英词缀

精英出现概率约 15%，生命 ×3，并获得一个词缀：

| 词缀 | 效果 |
| --- | --- |
| 迅捷 | 移速 +28% |
| 坚韧 | 最大生命 +35% |
| 爆裂 | 死亡时爆炸，伤害附近塔和英雄 |
| 护咒 | 受到伤害 -20% |

精英有金色环和“精英·词缀”标签。

## 攻击锁定

- **攻城组**：工兵、自爆兵、迫击兵锁定附近塔
- **猎杀组**：冲锋兵、猎犬锁定英雄
- **远程组**：弓手射击英雄
- **支援组**：萨满治疗附近怪物
- **Boss**：优先攻击附近塔，同时远程射击英雄，近核心时攻击核心
- 其余怪物继续沿流场压核心

这样塔不再是“只挨打不吸引仇恨”的背景，英雄也不能完全无脑站桩。

## Boss 阶段

- 66% / 33% 血触发
- 召唤援军
- 360 半径冲击波
- 附近塔受伤并静默 1.6～2.0 秒
- 血条显示阶段

## 验证

- `tools/verify_arena.ps1`：77 项检查
- 20 塔 + 120 怪压力探针：300 帧平均 **6.0ms/帧**（headless，参考值）
- 4 塔 + 英雄不输出：**可胜但很不稳定**（两次分别 6 / 12 次漏怪，核心 616 / 490）
- 5 塔：胜，核心 700，0 漏怪
- 6 塔：胜，核心 644，3 漏怪
- 因此 4 塔已不再是必败边界，失败边界下移到 2～3 塔；后续需要继续压 4 塔
- 新增测试：
  - 出怪预警存在，且延迟后才出怪
  - 猎犬高速且冰弱点
  - 精英获得词缀
  - 萨满治疗
  - 分裂体死亡分裂

# 后续工作

## 真人试玩

同一阵容和初始预算下，观察玩家能否从预览决定守哪一路。森林比较骑士普攻与推敌回塔下，溪谷记录签悬赏后是否换旗，遗迹比较收墙时机。密集战斗时观察攻击目标、命中和危险预告能否看清。代码回归与自动战果见[验收记录](STAGE_CLOSEOUT.md)。

## 搁置的森林巢穴

原型让地表与巢内共享出兵口和同一波的待发队列。留在地表也能接住完整主队。英雄进洞可截击守卫、推挡木延迟后队、开回程侧道，再根据防线预警撤回。早期独立样板还试过贡献经验、孵化量、巢心和破核反扑。

原型固定三塔的前三波分别出洞 8、12、12 只；挡木使后队抵达首弯晚约 5.73 秒。旧经济下的这一结果供恢复项目时对照。恢复时先复测跨区前后的待出与存活计数、在地表能否读懂出兵、英雄回防可达性，再评估与正式波间规则及金币结算的兼容性。争地、反夺和修塔也继续搁置。

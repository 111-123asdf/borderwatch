## 数值是小样起点，不是免验收指令

- 放大只先调整视觉、阴影和对应效果，不自动扩大碰撞、射程或拦截容量。高塔、首领、道路遮挡分别检查，不能把所有图片盲乘1.3。
- 普攻不加全局顿帧。命中闪白60ms、挤压1.15/0.85并约120ms恢复、技能局部停顿50—70ms作为初始参数；减少闪烁模式使用柔和替代。
- 大招80—100ms全局顿帧和1.03镜头推近仅作为实验场可比较选项，默认先关闭。全图边缘和基地不能被裁切。全局反馈用真实时间限流，至少间隔0.4秒。
- 只冻结需要表现的角色，不用阻塞sleep卡住游戏主线程。输入、暂停、冷却、波次与结算的时间语义须独立说明。命中只能结算一次，退出/重开清除冻结状态。
- 震屏采用衰减创伤值，最大偏移6px作为起点，只给重要事件；普通普攻不持续震屏。减少动态设置可关震屏、推近和强闪烁。
- 金币资源仍即时、一次性到账，飞行图标只做视觉回报。死亡效果不能延迟死亡判定、奖励或拦截释放。
- 伤害数字先仅显示英雄伤害，150ms内按目标合并。没有暴击事件时不新增暴击规则，不把高伤害伪称暴击。
- 建造/升级动效只作用视觉层，底部接触中心、碰撞、塔位和实际等级保持准确；开火后坐作用可动部件，不能摆动整座塔。
- 程序绘制保留必要的范围、危险预告与调试；主要命中画面逐步改用成套精灵或粒子。音频与字体采用逐文件授权记录，不把素材站名字当授权证明。
